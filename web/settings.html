Where does this run?

The browser displays the workspace. The Python backend handles research, model requests and training on your chosen computer or GPU server.

GitHub Pages can host a static frontend, but cannot run Python, Codex, Claude Code or GPU jobs. This version uses a private backend and SSH forwarding. A public multi-user service needs separate authentication, user isolation and an authenticated API.

CLI login belongs to the account running the backend. On a remote server, sign in there. This page does not embed a third-party OAuth login.

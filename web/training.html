Method and measurement scope

Each task actor observes one gradient Gram row and its training loss. Four centralized critics each see all task observations and actions. A shared reward and replay buffer train the policies. Inference uses the trained UniBrain checkpoint.

Select a recorded update to inspect its coordinator profile.

TaskForce also uses loss, gradient and reward normalization. UniBrain uses a different task graph and model optimizer; this is a task adaptation, not a reproduction of its reported benchmarks. Validation does not drive the reward. An autograd path establishes connectivity, not a nonzero gradient or convergence.
